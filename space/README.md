# FaceForge

Live demo of a conditional DCGAN trained on CelebA. Pick attributes (male, smiling,
eyeglasses, blond hair, black hair, young) and a seed to generate 64x64 faces.

Source code: https://github.com/Naman-verma-02/faceforge-gan
